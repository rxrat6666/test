# Баг-репорты
Для каждого инцидента: запустить `dart run bin/main.dart` на исходной версии из evidence/before_fix и найти INC-N.

## BR-1 (INC-1) — не учитывается количество
Критичность: High. Ожидалось 2700, получено 900. Причина: calculateTotal не умножала на quantity. Исправление: умножение на количество. Тест: inc1_pricing_test.dart.

## BR-2 (INC-2) — ложный успех сохранения
Критичность: Critical. Ожидалось false, получено true при лимите 3. Причина: catch логировал ошибку, но возвращалось true. Исправление: вернуть false в catch. Тест: inc2_storage_test.dart.

## BR-3 (INC-3) — ресурс остаётся открытым
Критичность: High. Ожидалось успешное создание второго отчёта, фактически StateError. Причина: close пропускался при исключении. Исправление: finally. Тест: inc3_reports_test.dart.

## BR-4 (INC-4) — история пустая
Критичность: High. Ожидалось 3, получено 0. Причина: Future.then не ожидался. Исправление: await. Тест: inc4_history_test.dart.

## BR-5 (INC-5) — неверная доставка на пороге
Критичность: Medium. Ожидалось 0, получено 500. Причина: строгое сравнение >. Исправление: >=. Тест: inc5_shipping_test.dart.

Окружение: Dart 3.x, Linux (GitHub Actions). Фактическую версию SDK и точные строки логов можно взять из результатов CI.
