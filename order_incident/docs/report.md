# Итоговый отчёт
Я разобрал пять инцидентов учебного сервиса заказов и исправил их первопричины.

| Инцидент | Дефект | Критичность | Исправление | Тест |
|---|---|---|---|---|
| INC-1 | Вычисление | High | * quantity | inc1 |
| INC-2 | Обработка ошибок | Critical | false при ошибке | inc2 |
| INC-3 | Ресурс | High | finally | inc3 |
| INC-4 | Асинхронность | High | await | inc4 |
| INC-5 | Граница | Medium | >= | inc5 |

Самая полезная запись — про количество и вклад позиции: сразу видно, что множитель потерян. Сложнее всего без логов было бы найти проблему асинхронности: история возвращалась до прихода ответа. Я бы добавил регрессионные тесты, обязательное ревью и логирование важных событий.

Фактические результаты запуска см. в GitHub Actions.
