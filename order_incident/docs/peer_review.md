# Перекрёстная проверка
Для реальной сдачи нужно обменяться работой с одногруппником. Я подготовил чек-лист: воспроизводимость, ожидаемые/фактические значения, первопричина, регрессионный тест, отсутствие секретов. Три замечания (Blocker/Major/Minor) и имя проверяющего заполняются после настоящей проверки.
